⭐ GeoSUAS Mogi

Projeto - Extração, Tratamento e Apresentação de Dados

GEOSUAS Mogi

🔗 Links:

🚀 Website 🛈︎ GitHub

▶ Resumo

Desenvolvimento de aplicação web para contornar limitações na funcionalidade de mapas do VISUAS, utilizando Python, Pandas, Folium, JavaScript, HTML/CSS e Bootstrap. Integração e tratamento de bases governamentais com milhares de registros e aproximadamente 600 pontos de referência, utilizando GeoJSON para delimitação territorial e disponibilizando os dados em mapa interativo e responsivo.


A solução permanece em uso por funcionários da rede, facilitando o acesso e a visualização georreferenciada de informações sobre serviços socioassistenciais de Mogi das Cruzes.

⭐ Como escolher seu modelo de celular ideal?

Projeto · Análise de Dados

Como escolher seu modelo de celular ideal?

🔗 Links:

🚀 Website 🛈︎ GitHub

▶ Resumo

Análise exploratória de 998 modelos de smartphones utilizando Python, Pandas, Streamlit, Plotly e SQL (pandasql), abrangendo tratamento e padronização dos dados, distribuição de preços e marcas, categorias de mercado e comparações entre preço, benchmark, fabricante e sistema operacional.


A análise identificou padrões de custo-benefício e discrepâncias de preço entre fabricantes e categorias, além de diferenças de desempenho entre versões de Android e iOS, consolidando os resultados em uma aplicação interativa com visualizações e conclusões analíticas.

⭐ Games Sales with 100k+ units

Projeto · Dashboard

Games Sales with 100k+ units

🔗 Links:

🚀 Website

▶ Resumo

Desenvolvimento individual de dashboard em PowerBI para análise de 11.487 jogos de videogame com mais de 100 mil unidades vendidas, incluindo tratamento e organização dos dados e construção de visualizações interativas.


O dashboard apresenta análise das vendas por plataforma, ano, região, gênero e publisher, com filtros e cruzamentos dinâmicos para identificar padrões de desempenho entre diferentes consoles, períodos e empresas, além de rankings dos jogos mais vendidos conforme os critérios selecionados.
